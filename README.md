# GitHub User Activity CLI

A simple Java command-line application that fetches and displays the recent public activity of a GitHub user using the GitHub API.

## Features

- Fetch recent events (Pushes, Stars, Issues, etc.) directly from GitHub.
- Clean and formatted terminal output.
- No external dependencies required (Standard Java Library only).

## Prerequisites

- **Java JDK 11** or higher installed.

## How to Run

Follow these steps to compile and run the application on your machine:

1. **Clone or download** the `Program.java` file.
2. **Open your terminal** in the folder where the file is located.
3. **Compile the program:**
   ```bash
   javac Program.java
4. **Usage Example** 
   ````bash
   java Program <username>
